# Doctor Bot

ربات بررسی نوبت پزشک

## امکانات

- بررسی خودکار نوبت پزشک
- پشتیبانی از چند پزشک
- ارسال اعلان تلگرام
- جلوگیری از ارسال پیام تکراری
- اجرای دائمی روی Render

## تنظیمات

متغیرهای محیطی مورد نیاز:

TELEGRAM_BOT_TOKEN

TELEGRAM_CHAT_ID

## اجرا

Render به صورت خودکار برنامه را اجرا می‌کند.
